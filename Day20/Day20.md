Day 20 - AI Powered Face Puzzle Game

Objective

Built an AI-powered face puzzle game using HTML, CSS and JavaScript.

Features Implemented

- Webcam access using getUserMedia()
- Live camera preview
- Face photo capture
- Puzzle generation (3×3, 4×4, 5×5)
- Drag and drop support
- Touch support for mobile devices
- Move counter
- Live timer
- Correct piece tracking
- Win detection
- Results screen
- Local leaderboard using localStorage
- Responsive design

Learning Outcomes

- Camera API
- Canvas image processing
- Puzzle generation logic
- Drag and drop interactions
- Mobile touch events
- LocalStorage implementation
- Responsive UI design
