# Day 17 – AI Vehicle Cost & Fuel Analysis Dashboard

## Objective
Built an AI-powered Vehicle Cost & Fuel Analysis Dashboard using a provided E85 vehicle dataset.

## Dataset
- File: day17_e85_dataset_optimised.csv
- Records: 52
- Features:
  - Fuel Type
  - Vehicle Age
  - Distance Travelled
  - Fuel Cost
  - CO₂ Emissions
  - Maintenance Cost
  - Refuel/Recharge Time
  - Fuel Price
  - Mileage

## Analysis Performed
- Cost per Kilometer Analysis
- CO₂ Emission Analysis
- Maintenance Cost Analysis
- Fuel Comparison
- Vehicle Age Impact Analysis
- E85 Economics Evaluation
- Monthly Running Cost Estimation

## Dashboard Features
- KPI Cards
- Cost per KM Comparison
- CO₂ Emission Visualization
- Fuel Type Comparison
- Vehicle Age Cost Trend
- E85 Score Gauge
- Environmental Impact Analysis

## Key Findings
- E85 offers lower fuel prices than Petrol.
- Running cost depends on mileage efficiency.
- EV shows the lowest CO₂ emissions.
- Maintenance costs vary significantly across fuel types.
- Vehicle age increases maintenance expenditure.

- Data-driven cost analysis

- Dashboard design using HTML, CSS, JavaScript
- KPI visualization
- Environmental impact assessment
