Day 16 – Build Your First Stock Research Skill

Objective

Created a reusable Claude Custom Skill for stock fundamental analysis and company research.

Skill Name

stock-fundamental-research

Description

Analyzes Indian and global listed companies using fundamentals, valuation metrics, financial statements, ownership trends, competitive advantages, risks, and growth prospects.

Activities Completed

- Created a custom Claude Skill
- Added stock research instructions
- Tested with TCS stock analysis
- Compared TCS vs Infosys
- Reviewed valuation metrics
- Studied ownership and risk factors

Key Learnings

- Learned how reusable AI Skills work
- Understood stock fundamental analysis workflow
- Explored valuation concepts such as PE, PB, ROE and ROCE
- Learned how AI can generate structured company research reports
- Compared multiple stocks using a repeatable framework

Output Generated

- Single stock research report
- Stock comparison report
- Valuation and ownership analysis
- Risk assessment summary

Conclusion

Successfully built and tested a reusable stock research assistant using Claude Skills. The workflow can now be reused without rewriting prompts for every stock analysis request.
