# Day 5 - Context Engineering

## Topic
Context Engineering

## Prompt A (Without Context)

Create a 30-day learning roadmap.

Include:
- Weekly milestones
- Daily tasks
- Resources
- Projects
- Final outcome

Make it practical and beginner-friendly.

## Observation

The roadmap was generic and designed for any learner.
It did not consider my goals, skills, or available time.

---

## Prompt B (With Context)

Current Situation: Fresher

Current Skills:
- Web Development
- Design
- AI Tools
- Prompt Engineering

Goal:
- Get a Job
- Build a Digital Agency

Available Time:
- 4 Hours Per Day

Experience Level:
- Beginner

Preferred Learning Style:
- Projects + Videos

## Observation

The roadmap was personalized to my career goals.
It included relevant projects, learning priorities, and realistic milestones.

---

## Comparison

### 1. Which roadmap feels more personalized?
Prompt B

### 2. Which roadmap would you actually follow?
Prompt B

### 3. What role did context play?
Context helped AI understand my current situation, goals, skills, and constraints.
This resulted in a more useful and actionable roadmap.

---

## Key Learning

Better Context = Better Output

The more relevant information we provide to AI, the more accurate, personalized, and practical the response becomes.
